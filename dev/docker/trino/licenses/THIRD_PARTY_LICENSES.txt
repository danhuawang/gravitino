5. Recommended Finalization Process

Before final release, generate a complete third-party license inventory from the actual build output. Recommended sources include:

a. Java dependency license reports from Maven or Gradle
b. Web UI dependency license reports from npm, pnpm, or yarn
c. Container image SBOM generated by Syft, CycloneDX, SPDX-compatible tooling, or equivalent tooling
d. Manual review of any bundled scripts, binaries, connectors, or vendor-provided files

Final entries should include at least:

Version
License
Copyright holder, when available
Project URL, when available
